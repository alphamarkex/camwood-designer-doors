# CAMWOOD animated website

Standalone static website concept for CAMWOOD Designer Doors.

## Features
- Cinematic intro wordmark
- Animated hero and CSS door-panel opening
- Responsive mobile navigation
- Scroll-triggered reveal animations
- Collections for membrane, texture, digital, and windows/glass
- Reduced-motion accessibility support

## Run locally
Open `index.html` in a browser or run `python -m http.server 8000`.

## Before publishing
1. Upload the `assets/` directory from the supplied project ZIP to this repository. The HTML and CSS reference these files: `membrane-range.jpg`, `texture-range.jpg`, `digital-range.jpg`, `windows-range.jpg`, and `membrane-door-interior.jpg`.
2. Replace the placeholder email `hello@camwooddoors.com` with the verified CAMWOOD contact.
3. Verify company claims, logo, and contact details.
4. Connect an enquiry form/backend if required.

This is a frontend prototype; it is not yet connected to a CMS or enquiry backend.
